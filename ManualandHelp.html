Manual and Help

A online manual is available at: HPx-Cement/Cement Module at main · dphjacques/HPx-Cement


There are several tutorials available explaining how to simulate different cement systems and processes.


The graphical user interface provides links to selected topics in the online manual. These links are available for the input table form for a template. Follow the instructions below to view the Help panel for a specific input in the template (see video tutorial below).


Open the help panel by clicking on the main menu.


There are three options for viewing the help:

1. The help panel appears at the right in the graphical user interface

2. The help panel appears at the bottom in the graphical user interface

3. The help panel floats


In the help panel, select the Global Variables tab

In the input table form, click a question mark
