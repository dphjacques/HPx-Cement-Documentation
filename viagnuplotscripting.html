via gnuplot scripting

In the current version, the changes on a ternary graphs can only be done via gnuplot script commands. These commands are illustrated in the tutorial Blending of OPC with GFBS and SF in variable amounts (ternary) (see TB_Ternary).

Scale of the axes


Zooming in a specific region of the ternary graph are set with TERNARY_X_MIN, TERNARY_X_MAX, TERNARY_Y_MIN, TERNARY_Y_MAX, TERNARY_Z_MIN, and TERNARY_Z_MAX.

To be valid, an equilateral triangle subregion needs to be defined constraint by a total sum of 100. Three variables are independent, three are dependent.

If the minimum values for each axis are defined, the zoom region is set via


TERNARY_X_MIN = 70

TERNARY_Y_MIN = 0

TERNARY_Z_MIN = 0

L = 100 - TERNARY_X_MIN - TERNARY_Y_MIN - TERNARY_Z_MIN 


TERNARY_X_MAX = TERNARY_X_MIN + L

TERNARY_Y_MAX = TERNARY_Y_MIN + L

TERNARY_Z_MAX = TERNARY_Z_MIN + L


If the range of one of the axis is set together with the minimum of of another axis, the zoom region is set via (X full range and Y minimum value)


TERNARY_X_MIN = 60

TERNARY_X_MAX = 85

TERNARY_Y_MIN = 15

L = TERNARY_X_MAX - TERNARY_X_MIN 


TERNARY_Y_MAX = TERNARY_Y_MIN + L

TERNARY_Z_MIN = 100 - TERNARY_X_MIN - TERNARY_Y_MIN  -L

TERNARY_Z_MAX = TERNARY_Z_MIN + L


If unacceptable values are selected, the ternary graph will have an invalid zoom region and other values need to be defined. A quick check is 


Xmin + Ymin + L ≤ 100


When a zoom region is defined, tic length may become too long - the default value is 2. When defining the zoom region, a good rule of thumb for setting the tic length is 2.0*L/100 (given L is defined as above) using TERNARY_TIC_LENGTH:


       TERNARY_TIC_LENGTH = 2.0*L/100



Labels and Grid

The label and grid spacing are set with TERNARY_X_STEP, TERNARY_Y_STEP, and TERNARY_Z_STEP, for example


TERNARY_X_STEP = 5

TERNARY_Y_STEP = 5

TERNARY_Z_STEP = 5


Removing grid lines is done with TERNARY_NO_GRID. When it is set to 1, grid lines will not appear (default value is 0 with grid lines displayed). When defining a zoom region, some tics may disappear - this issue is not solved yet. Removing the grid lines (TERNARY_NO_GRID = 1) will solve this.


Colour scale

The colour is defined with the set palette commands from gnuplot. The default values are:


set palette maxcolors 10

set palette model RGB

set palette defined (0 "web-blue" , 0.25 "light-blue", 0.5 "web-green", 0.75 "yellow" , 1.0 "red")


The colorbox is defined with the set colorbox command, colorbox tics and labels with set cbtics. The default values are:


set colorbox vertical user origin 0.85,.175 size .03,.725 

set cbtics scale 0
