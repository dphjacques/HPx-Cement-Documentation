  1. Notes on Models for Cement Systems

Cement Models

For each thermodynamic database (and for a specific version of the database), a cement model for each cement system is defined.


In this version of the module, the are applicable for ordinary Portland cements of the type CEM-I, CEMII, and CEM III.


Below are default the mineral assemblages (mineral names and formula are given here). Note that the default models can be adapted - See Adapt cement models.


Internally, each system is identified by a number. A basic system contains either Ca Si Al S Mg C or Ca Si Al/Fe Mg C and can be extended with Cl, Na and K.

Each system can be extended by including zeolites. Ca-zeolites are always included; Na-zeolites and K-zeolites if the basic system contains Na or K.
